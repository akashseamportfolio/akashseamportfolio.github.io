Studio Desk on GitHub

Edit your portfolio from this page. Drafts and uploads stay in your private GitHub repository. Publishing copies the chosen pages to GitHub Pages.

First-time setup
  1. Create the Pages repository named akashseamportfolio.github.io. Choose Public and Add a README. Keep the existing akash-seam-portfolio repository private.
  2. Create a fine-grained GitHub token. Select only these two repositories. Set repository Contents: Read and write and Pages: Read and write. Choose an expiry you can renew when needed.
  3. Enter that token below. From this existing setup page, use Copy existing portfolio to migrate drafts and media.
  4. In Publishing, choose Set up Studio Desk · keep portfolio offline. Then open GitHub Pages settings and choose Deploy from a branch → main → / (root).

The website remains an unavailable page until you choose Publish. Studio Desk stays at /admin/ when the portfolio is offline.

The token stays in this open browser session. It is not saved in the site, repositories or browser storage.

Bring your portfolio across

Copy the current draft, published version, media and history into the private repository. Nothing is published by this step.
