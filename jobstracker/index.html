First-time setup / reconnect instructions

First-time setup

  1. Open Google Cloud Personal mode setup. Sign in using the account where you want to store your tracking. Create a personal project, select Web application, and create the client. If Personal mode is unavailable, use Google Auth Platform, configure External audience and add yourself as a test user.
  2. In the same project, open Google Drive API and click Enable if needed.
  3. Open OAuth Clients and select your Web application client. Under Authorized JavaScript origins, add the exact origin below (no /jobstracker path). Save. No redirect URI is needed for this popup flow.
    https://akashseamportfolio.github.io
  4. Copy the Client ID (ending in .apps.googleusercontent.com), paste it into the field above, then click Connect Google Drive from the deployed tracker. Approve access to its own configuration data. Look for Synced to private Google Drive.

For an External test app, if required, use Data Access to add https://www.googleapis.com/auth/drive.appdata and Audience to manage test users.

Reconnect or use another device

Open the deployed tracker, go to Drive sync settings, reuse the original client ID if the field is blank, and click Connect Google Drive. Select the same Google account. If needed, click Sync now. To recover your original client ID, open the OAuth Clients link above and select the original project. Do not create a replacement project merely to reconnect; its app-specific data may be separate.

Troubleshooting

Origin mismatch: check the exact authorized origin and use the deployed HTTPS site. API disabled: enable Drive API in the correct project. Popup blocked: allow Google sign-in popups. Expired session: reconnect. Disconnect keeps local changes and does not delete Drive files. Export a backup before clearing browser data, revoking access or changing projects.
